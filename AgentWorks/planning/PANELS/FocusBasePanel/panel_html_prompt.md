# FocusBasePanel HTML Prompt

380px 너비 브라우저 extension popup을 디자인한다. 상단에는 Focus Sprout 로고와 설정 버튼, 중앙에는 부드러운 초록색 원형 정원 안의 식물, 그 아래 큰 타이머와 상태 라벨을 배치한다. 주요 실행 버튼은 하나의 넓은 pill button으로 강조하고 초기화는 보조 버튼으로 둔다. 하단에는 오늘 4회 목표의 progress dot과 완료 횟수를 표시한다. 따뜻한 cream 배경, 진한 forest 텍스트, lime accent를 사용하고 compact하지만 답답하지 않게 구성한다. 모든 버튼은 keyboard focus 상태를 가진다.
